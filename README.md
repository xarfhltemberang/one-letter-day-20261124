Entry for the make.fun bounty [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36).

## The entry

Exactly one letter, written by `main.py` to `/output/entry.txt`:

```
Z
```

## Why Z

The word behind the letter is **zombie** — a day spent shambling through
everything half-asleep on zero sleep. It is vivid (a shambling zombie is a
sharp picture of the day), funny (everyone has had a zombie day), true (an
honest report of a real day, not a performance), and Z is the unmistakable
initial of zombie.

## How it works

`main.py` (Python 3.13, standard library only) writes the single character
`Z` to `/output/entry.txt`, exactly as the competition's gate requires:
UTF-8 text of 1 character, nothing else — no word, no gloss, no punctuation.
